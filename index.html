Key Suite Features

Designed from the ground up for strict privacy, ease of use, and self-hosted control.

Single Password Encryption

Authenticate once per session. Your master password derives client-side keys to decrypt both your emails and CryptPad documents simultaneously.

Unified Logout Routines

Logging out from either Webmail or CryptPad instantly clears state and logs you out across all apps and active sessions globally.

Key Synchronization

Seamlessly sync PGP and document encryption keys across authorized user devices without compromising Zero-Knowledge architecture.

Account Provisioning

Sysadmins can provision LDAP accounts as they usually do. Users initialize their master password safely via /init.

Modern Refreshed UI

CryptPad and Bulwark Webmail have been visually overhauled to deliver a sleek, modern, cohesive dark design theme across the entire suite.

Security Model

Zero-Knowledge & Ephemeral Secret Sharing

Secrets are kept strictly in client RAM using Argon2id and HKDF derivation. Cross-origin secret transfers use non-extractable AES-GCM keys with server-side ephemeral RAM storage (5-minute max TTL with Burn-on-Read guarantees).

Argon2id Client-side hashing
HKDF SHA-256 Domain-isolated sub-keys
AES-GCM 256 In-memory wrapping
